# Beecrowd 1059 - Números Pares

## Descrição

Este programa resolve o problema 1059 do Beecrowd, que consiste em imprimir todos os números pares entre 1 e 100, inclusive.

## Tecnologias utilizadas

- Java
- NetBeans
- Maven

## Entrada

Este problema não possui entrada.

## Saída

O programa deve imprimir todos os números pares entre 1 e 100, inclusive, um número por linha.
